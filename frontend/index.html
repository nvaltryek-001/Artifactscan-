CAPTURE GUIDANCE

For a good reconstruction

  • 20–80 sharp photos walking a full circle around the object.
  • 60–80 % overlap between neighbouring shots; small steps beat big jumps.
  • Diffuse, constant light. Avoid flash, hard shadows and moving light.
  • Textured surfaces reconstruct well; glass, chrome and plain white do not.
  • Add a scale bar if you need real-world measurements later.

How to enable the classifier
  1. pip install -r ml/requirements.txt
  2. python ml/download_imet.py — CC0 images from The Met's Open Access collection
  3. python ml/train_classifier.py — ResNet-18 transfer learning, metrics written to logs/
  4. Restart the server. This page then runs real inference.
